# Diagramas

**Lector:** personas

Los diagramas de los documentos. Cada uno tiene dos archivos con el mismo nombre:

- `nombre.html`: el original, el que se edita.
- `nombre.png`: la imagen exportada del HTML, la que se ve en el documento.

En el `.md` va la imagen y debajo el enlace al HTML, con la ruta relativa desde ese documento (`../diagrams/` desde `arquitectura/` o `guias/`). Si cambias el HTML, vuelve a exportar el PNG: uno sin el otro dicen cosas distintas.
