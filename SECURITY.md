# Security policy

## Supported versions
| Version | Supported |
|---|---|
| Latest release (0.x) | yes |
| Older releases | no |

## How to report a vulnerability
**Do not open a public issue.** Use «Report a vulnerability» in the repository's [Security tab](https://github.com/partprogramming09/vegaflow-universal/security/advisories/new). Include what you found, how to reproduce it and what impact you think it has.

VegaFlow runs with administrator rights and writes to the registry, power plans and some game files, so reports about paths it should never touch, anti-cheat detection, or restoring the registry are especially welcome.

## What to expect
We confirm receipt within 7 days and keep you posted on the fix. Please do not publish the details until a fixed version is out.
