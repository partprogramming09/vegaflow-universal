# What scripts/ci/host-unit-tests.sh builds on the host. Decided by hand (measured 2026-11-21), never guessed per run.
#   src      <file>          production file that compiles with tests/host/windows.h (put in an archive: the linker
#                            takes only the members a test uses)
#   test     <file>          unit-test file that compiles, links and passes on the host
#   exclude  <file> <reason> one word: compile = calls the Windows API or needs a Windows header beyond tests/host/,
#                            link = needs src/ code that only builds on Windows (text_convert, change_journal, steam,
#                            registry...), stub = reaches a stub in tests/host/host_stubs.cc (aborts when called)
# Every tests/unit/*_tests.cpp must be a test or exclude line. To re-check an exclusion after a change, move it to
# "test", run the script and read the error.
